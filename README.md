# JSP_Team3_Project
jsp팀프로젝트


# 필독

git clone 하고 프로젝트 연후에 team_website 폴더 안보이시면 

1. 상단 메뉴에서 File → Import
2. General → Existing Projects into Workspace 선택
3. Next 클릭
4. Select root directory에서 클론한 저장소 안의 team_project 폴더 선택


카카오지도 api키나 DB 사용자 이름, 패스워드는 config.jsp로 관리하고 있습니다. <br>
"JSP_Team3_Project\team_project\src\main\webapp\config.jsp" 해당경로에 config.jsp파일을 직접 넣어야 지도 api와 db연동이 정상적으로 작동합니다.<br>
해당 파일 추가 안되도록 .gitignore 설정했습니다만 api키는 git에 올리시면 안됩니다.<br>

서버는 tomcat 10.1이고 따로 설정 하셔야 합니다. 

추가로 DB설정시 유저 권한은 GRANT CONNECT, RESOURCE, DBA, CREATE SESSION, CREATE TABLE TO "사용자 이름"; 으로 했습니다.<br>

sqldatebase파일에 sql문 들어있습니다.


# 프로젝트 설명

DB설계를 번경했습니다 이미지 저장부분을 image_file 테이블로 관리 하고 admin 테이블을 추가해 위도 경도에 따라 담당 관리자가 정해집니다.
설계 했습니다.
 
    어드민 테이블
    CREATE TABLE admin 
        admin_no        NUMBER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY, -- 관리자 번호
        admin_name      VARCHAR2(50) NOT NULL, -- 관리자 이름
        id              VARCHAR2(30) NOT NULL UNIQUE,   - 관리자 로그인 아이디
        password        VARCHAR2(50) NOT NULL,         -- 비밀번호
        role            VARCHAR2(30) DEFAULT 'ADMIN'   - 권한

    신고게시물 테이블
    CREATE TABLE report 
        report_id       NUMBER  -- 게시물 ID 기본키
        user_name       VARCHAR2(20) NOT NULL,  -- 작성자 이름 (일반유저)
        title           VARCHAR2(200) NOT NULL,   -- 제목
        waste_type      VARCHAR2(50) NOT NULL,  -- 쓰레기 유형
        latitude        VARCHAR2(10) NOT NULL,  -- 위도
        longitude       VARCHAR2(10) NOT NULL,  -- 경도
        content         CLOB,                   -- 상세 내용
        status          VARCHAR2(30) DEFAULT '접수', -- 접수상태 
        reg_date        DATE DEFAULT SYSDATE,       -- 작성 시간
        admin_no        NUMBER REFERENCES admin(admin_no)  -- 처리를 맡은 관리자 번호 (참조키)


    사진 파일 테이블
    CREATE TABLE image_file (
        file_id         NUMBER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,-- 파일 번호 기본키
        report_id       NUMBER NOT NULL REFERENCES report(report_id) ON DELETE CASCADE, --게시물 id를 참조 
        file_name       VARCHAR2(255) NOT NULL -- 파일 이름
    );

#
카카오 지도api는 https://apis.map.kakao.com/web/ 해당 사이트 참고해 작성했습니다.<br>
사진업로드를 위한  파일 입출력 부분은 오픈라이브러리 cos.jar를 이용해서 작성했습니다, jsp교재에 파일업로드 부분 참고 하시면 됩니다.
스타일 서식은 src/main/webapp/stylefile 파일에 .css파일로 따로 관리하고 있습니다.

---

main.jsp는 시작 화면이고 현재 접수된 신고를 보여주는파일입니다.<br>
write.jsp는 신고 게시물 작성 화면으로 지도를 클릭해 위도 경도를 받아옵니다.<br>
list.jsp는 신고 게시판으로 write.jsp에서 작성된 신고를 볼수 있습니다.<br>

---

현재 main.jsp와 write.jsp,write_process.jsp부분은 거의 구현했습니다만 추후 기능 변화가 있으면 수정이 필요할거 같습니다.<br>
지금 사진파일이 여러장 올려도 데이터베이스에 하나밖에 안올라가는 문제가 있습니다.<br>
list.jsp는 아직 구현 안했습니다.
